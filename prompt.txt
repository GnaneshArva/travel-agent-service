Application Name
travel-agent-service

Part 1 — Foundation & Architecture
Objective
Build an Enterprise-grade Agentic AI Travel Planner using Python 3.12+ and the OpenAI Agents SDK.
This application is the central orchestration layer of the entire Enterprise AI Travel Platform.
Its responsibility is NOT to implement business logic directly. Instead, it coordinates multiple platform services to fulfill a user's travel request.
The Travel Agent Service should:
Accept user travel requests
Build conversational context
Retrieve long-term memory
Retrieve enterprise knowledge
Plan tasks
Select and invoke MCP tools
Interact with the LLM using the OpenAI Agents SDK
Validate requests and responses through Guardrails
Record execution traces through Observability
Load versioned prompts through Prompt Management
Return structured responses
The application must be modular, maintainable, testable, and aligned with enterprise software engineering best practices.

Performance Goals

Reuse context during a request where appropriate.

Stream responses when supported.

Use configurable timeouts and retries.

Avoid blocking I/O.
